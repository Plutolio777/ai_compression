# AI压缩平台 - 项目结构文档

## 技术栈

### 前端技术栈

- Vue 3 (Composition API)

- PostCSS
- Less (用于样式预处理)
- Vue Router
- Vuex
- ecarts
- element-plus

### 后端技术栈

- Python 3
- Django
- uv 一个用 Rust 编写的极快的 Python 包和项目管理器

## 主要文件功能

### 核心配置

- `vite.config.js`: Vite构建配置
- `tailwind.config.js`: TailwindCSS配置
- `postcss.config.js`: PostCSS插件配置

### 入口文件

- `main.js`: 应用初始化，挂载根组件
- `index.html`: 应用HTML模板

### 功能模块

- `src/api/apiService.js`: 封装axios请求，处理API调用
- `src/polling/index.js`: 实现轮询逻辑，用于实时数据更新
- `src/router/index.js`: 定义前端路由
- `src/store/index.js`: 全局状态管理

## 开发规范建议

1. **组件规范**:
   - 使用Composition API编写组件
   - 组件文件使用PascalCase命名 (如 `MyComponent.vue`)
   - 单文件组件结构顺序: template → script → style

2. **样式规范**:
   - 优先使用Tailwind工具类
   - 复杂样式写在`src/style/`目录下
   - 全局样式变量定义在`common.less`

3. **代码组织**:
   - 业务逻辑尽量封装到composables/目录
   - 工具函数放入utils/目录
   - API接口按模块划分

4. **提交规范**:
   - 遵循Conventional Commits规范
   - 提交前运行lint检查
